# PipeWire и аудиоинтерфейс

PipeWire управляет потоками аудио; совместимость с JACK позволяет подключать профессиональные аудиоприложения.

Минимальный фрагмент для адаптации в существующей конфигурации NixOS:

```nix
security.rtkit.enable = true;
services.pipewire = {
  enable = true;
  alsa.enable = true;
  pulse.enable = true;
  jack.enable = true;
};
```

Не добавляй второй конфликтующий аудиосервер. 32-битная ALSA-совместимость нужна только соответствующим приложениям. Сначала сравни фрагмент со своей конфигурацией и документацией её релиза.

В DAW выбери доступный подходящий backend и интерфейс, проверь вход и выход. Если используется JACK-режим, нужна работающая PipeWire-JACK совместимость. Граф подключений удобно проверять графическим patchbay, например qpwgraph, если он доступен в твоём nixpkgs.

[Официальная документация](https://wiki.nixos.org/wiki/PipeWire). Настройки на твоём устройстве не проверены.
