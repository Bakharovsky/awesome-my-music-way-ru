# Форматы плагинов

Плагин — модуль внутри DAW; standalone — отдельная программа. Один продукт может поставляться в нескольких форматах.

| Формат | Практическое правило |
|---|---|
| Linux VST2 | Обычно .so; сканируй папку VST |
| Linux VST3 | Bundle .vst3; сохраняй всю структуру |
| LV2 | Не рассчитывай на прямую загрузку в Waveform |
| CLAP | Наличие у плагина не гарантирует поддержку твоей версией Waveform |
| Windows VST | На Linux требует совместимого моста и Wine |
| AU / AAX | Не вариант для этой Linux-студии |

Начни с нативного Linux VST2/VST3 правильной архитектуры. Расширение .vst3 само по себе не означает, что файл предназначен для Linux.

**Проверка:** объясни, почему установленный standalone Guitarix может не появиться в списке инструментов Waveform.
