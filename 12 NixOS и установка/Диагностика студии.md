# Диагностика студии

| Симптом | Проверять по порядку |
|---|---|
| Нет звука вообще | Выход интерфейса → системная маршрутизация → master и mute |
| Нет записи | Физический вход → выбор mono-входа → arm → уровень предусилителя |
| MIDI молчит | Есть ли MIDI-ноты → инструмент на дорожке → диапазон нот сэмплера |
| Плагин не найден | ОС и архитектура → формат → путь → зависимости → журнал сканирования |
| GUI не открывается | Конкретная сборка → графические зависимости → запуск в другом пустом проекте |
| Щелчки | Буфер → нагрузка CPU → тяжёлые эффекты → частота устройства |
| Двойная гитара | Direct monitoring и DAW monitoring одновременно |
| Пустая библиотека | Путь к сэмплам → сохранённые ресурсы → разрешения |
| Звук изменился после обновления | Версия плагина → preset → ресурсы → сравнение с экспортом |

Меняй один параметр, записывай результат. Для воспроизведения проблемы сохраняй минимальный проект с одной дорожкой; не используй единственную копию песни как тестовый стенд.
