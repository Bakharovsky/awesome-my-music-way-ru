# Установка Waveform на NixOS

1. Сверь системные требования [Waveform Free](https://www.tracktion.com/products/waveform-free).
2. Проверь пакет в используемой ревизии nixpkgs. Поиск через registry — только ориентир:

```bash
nix search nixpkgs waveform
```

3. Если подходящего пакета нет, нужен собственный derivation или подходящее FHS-окружение для Linux-сборки. Не запускай Debian-установщик как системный менеджер пакетов NixOS.
4. При упаковке сохрани ресурсы приложения и зависимости. Разрешай unfree только если этого требует лицензия и метаданные выбранного пакета.
5. После установки проверь запись и экспорт на пустом проекте до установки остальных плагинов.

Здесь нет готового проверенного flake: неизвестны твоя ревизия nixpkgs и модель интерфейса. Linux upstream и пакет для NixOS — разные уровни совместимости.
