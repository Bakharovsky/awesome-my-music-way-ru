# Практика 17 — Закончить мини-трек

**Время:** три занятия по 45–60 минут.

## Сделай

Из восьмитактовой идеи собери 60–90 секунд: вступление, основная часть, контраст, конец. Добавь один автоматизированный переход. Настрой уровни, затем только нужные EQ и эффекты. Экспортируй и послушай вне DAW на умеренной громкости.

## Готово, когда

Трек имеет конец, не клиппует, открывается из резервной копии; записаны три конкретные задачи для следующей композиции.

- [ ] Сохранил проект и аудио.
- [ ] Проверил повторное открытие.
- [ ] Записал вывод в [Журнал занятий](../09%20%D0%9C%D0%BE%D0%B8%20%D0%B7%D0%B0%D0%BC%D0%B5%D1%82%D0%BA%D0%B8/%D0%96%D1%83%D1%80%D0%BD%D0%B0%D0%BB%20%D0%B7%D0%B0%D0%BD%D1%8F%D1%82%D0%B8%D0%B9.md).

## Что защитить на слух

Напой главный мотив без проекта и покажи его возвращение в форме. Назови один контраст нот/ритма и один контраст обработки. Мини-трек — промежуточный результат после этапов 7–9; финальная [Практика 26 — Хайперпоп из одной темы](%D0%9F%D1%80%D0%B0%D0%BA%D1%82%D0%B8%D0%BA%D0%B0%2026%20%E2%80%94%20%D0%A5%D0%B0%D0%B9%D0%BF%D0%B5%D1%80%D0%BF%D0%BE%D0%BF%20%D0%B8%D0%B7%20%D0%BE%D0%B4%D0%BD%D0%BE%D0%B9%20%D1%82%D0%B5%D0%BC%D1%8B.md) добавляет самостоятельную проверку изученных приёмов.
