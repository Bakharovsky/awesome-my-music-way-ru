# Практика 16 — Вокал и hard-tune

**Время:** 45–60 минут.

## Сделай

Спой короткий мотив из трёх нот. Сохрани оригинал. Сделай варианты без коррекции, с мягкой коррекцией и hard-tune. Затем отдельно измени форманты. Из одной гласной создай vocal chop.

## Готово, когда

Можешь объяснить разницу коррекции высоты и формант; у каждого варианта есть исходная запись.
