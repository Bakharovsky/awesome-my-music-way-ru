# Практика 03 — Два грува

**Цель:** Понять роль барабанов.

**Подготовка:** [Барабанный грув](../05%20%D0%9C%D0%B5%D0%BB%D0%BE%D0%B4%D0%B8%D1%8F%20%D0%B8%20%D1%81%D0%BE%D1%87%D0%B8%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5/%D0%91%D0%B0%D1%80%D0%B0%D0%B1%D0%B0%D0%BD%D0%BD%D1%8B%D0%B9%20%D0%B3%D1%80%D1%83%D0%B2.md) · [Velocity](../02%20%D0%A0%D0%B8%D1%82%D0%BC/Velocity.md) · [Половинное ощущение темпа](../02%20%D0%A0%D0%B8%D1%82%D0%BC/%D0%9F%D0%BE%D0%BB%D0%BE%D0%B2%D0%B8%D0%BD%D0%BD%D0%BE%D0%B5%20%D0%BE%D1%89%D1%83%D1%89%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%82%D0%B5%D0%BC%D0%BF%D0%B0.md).

## Действия

1. Собери 4/4: бочка 1 и 3, малый 2 и 4, хай-хэт восьмыми.
2. Скопируй клип и поставь бочку на каждую четверть.
3. В третьей версии оставь малый только на доле 3 для half-time.
4. Положи один и тот же рифф поверх всех версий, измени velocity хай-хэта.

## Готово, когда

Можешь простучать каждый рисунок и объяснить, почему ощущение меняется при одном BPM.

## Подсказка

Сначала используй только три звука ударных, чтобы слышать роли.
