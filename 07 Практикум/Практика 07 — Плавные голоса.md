## Действия

1. Оставь отдельный бас из практики 06.
2. В верхнем синтезаторе используй Am=A C E, F=A C F, C=G C E, G=G B D в близком регистре.
3. Сравни с перемещением всех трезвучий основным видом.
4. Добавь седьмую только в одном месте и сравни.

## Готово, когда

Различаешь смену аккорда, обращения и расположения; верхние голоса ведёшь намеренно.

## Подсказка

Обращение всей гармонии оценивают с учётом общего баса, а не только нижней ноты партии пэда.
