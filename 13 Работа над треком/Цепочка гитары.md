# Цепочка гитары

Рабочая отправная точка: **DI → мягкая чистка при необходимости → педаль → усилитель → кабинет → EQ → посылы**. BYOD необязателен; начать можно только с Guitarix.

1. Настрой гитару. Подключи к подходящему инструментальному входу, включи Hi-Z согласно инструкции интерфейса.
2. Выбери один mono-вход. Запиши сухой DI, слушая обработку в DAW.
3. Сначала найди звук усилителя и кабинета; добавляй gate и EQ по услышанной проблеме.
4. Для широкой рок-гитары сыграй два отдельных дубля и разведи их по панораме. Дублирование одного файла не равно двойному исполнению.
5. Сохраняй DI и пресет; экспортируй обработанную версию для восстановления.

**Проверка:** отключение плагинов возвращает чистую исходную запись.
