# Стартовый комплект

## Установить сначала

- Waveform Free: запись, встроенные сэмплеры, 4OSC и базовые эффекты.
- Surge XT: основной синтезатор; можно начать с 4OSC до его установки.
- Guitarix VST: обработка гитарного DI.
- Graillon Free: если записываешь голос.
- Небольшой набор WAV-ударных: kick, snare, clap, closed/open hat.

## Добавить для удобства

| Потребность | Инструмент |
|---|---|
| Акустические тембры | Decent Sampler + одна бесплатная библиотека |
| Подробная обработка | Выбранные модули LSP |
| Общая реверберация | Dragonfly Reverb |
| Необычные повторы | ChowMatrix |
| Перегруз | BYOD |
| Ленточная окраска | Chow Tape Model |

## Физический комплект

Гитара, исправный инструментальный кабель, аудиоинтерфейс с подходящим инструментальным входом, проводные наушники. Настрой гитару тюнером до записи. Для вокала понадобятся микрофон, подходящий кабель, стойка и желательно поп-фильтр. MIDI-клавиатура и мониторы могут подождать: ноты можно вводить мышью.

## Готовность

- [ ] Слышно метроном и записанный DI.
- [ ] MIDI играет через инструмент.
- [ ] Проект после перезапуска звучит так же.
- [ ] Экспортированный WAV открывается вне DAW.

Это полный набор задач для первых треков; устанавливать все эффекты в первый вечер не требуется.
