# Шаблон проекта Waveform

Создай в DAW один пустой проект и сохрани его как собственный шаблон. Здесь описана структура, а не готовый файл проекта Waveform.

| Дорожка | Содержимое |
|---|---|
| Drums | Micro Drum Sampler и четыре основных удара |
| Bass | Surge XT или 4OSC |
| Lead / Pad | Второй экземпляр выбранного синтезатора |
| Piano | Decent Sampler по необходимости |
| Guitar L / R | Два отдельных DI-дубля с Guitarix |
| Vocal | Сухая запись и Graillon |
| Chops / FX | Micro Sampler или аудиоклипы |
| Reverb return | Dragonfly либо встроенная реверберация |
| Delay return | Встроенный delay либо ChowMatrix |
| Reference | Референс для сравнения, исключённый из экспорта |

Пример старта: 120 BPM, 4/4, A minor, 48 кГц — творческие и технические отправные точки, а не правила жанра. Добавь маркеры intro, verse, chorus, outro. Отключи неиспользуемые тяжёлые эффекты.

**Готовность:** шаблон открывается без потерянных файлов; MIDI звучит; возвраты получают сигнал; master не перегружается.
