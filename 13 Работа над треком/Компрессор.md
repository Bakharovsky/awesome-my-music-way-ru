# Компрессор

Компрессор уменьшает динамический диапазон по заданным правилам. Threshold определяет уровень срабатывания; ratio — силу воздействия выше порога; attack и release — реакцию во времени. Реальная работа зависит от алгоритма.

Начни с умеренного ratio, затем подстрой threshold по исполнению. Слишком быстрая атака может сгладить удар, слишком длинный release — подавить следующую ноту. Make-up gain компенсирует уровень, а не доказывает улучшение.

**Попробуй:** сравни две атаки на snare, выровняй громкость. Опиши, как меняется начало удара.
