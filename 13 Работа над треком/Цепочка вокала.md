# Цепочка вокала

**Основа:** [Мелодия](../05%20%D0%9C%D0%B5%D0%BB%D0%BE%D0%B4%D0%B8%D1%8F%20%D0%B8%20%D1%81%D0%BE%D1%87%D0%B8%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5/%D0%9C%D0%B5%D0%BB%D0%BE%D0%B4%D0%B8%D1%8F.md) · [Аккордовые и неаккордовые звуки](../05%20%D0%9C%D0%B5%D0%BB%D0%BE%D0%B4%D0%B8%D1%8F%20%D0%B8%20%D1%81%D0%BE%D1%87%D0%B8%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5/%D0%90%D0%BA%D0%BA%D0%BE%D1%80%D0%B4%D0%BE%D0%B2%D1%8B%D0%B5%20%D0%B8%20%D0%BD%D0%B5%D0%B0%D0%BA%D0%BA%D0%BE%D1%80%D0%B4%D0%BE%D0%B2%D1%8B%D0%B5%20%D0%B7%D0%B2%D1%83%D0%BA%D0%B8.md) · [Автотюн и тональность](../06%20%D0%A1%D0%BB%D1%83%D1%85%20%D0%B8%20%D0%BF%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B2%20DAW/%D0%90%D0%B2%D1%82%D0%BE%D1%82%D1%8E%D0%BD%20%D0%B8%20%D1%82%D0%BE%D0%BD%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D1%81%D1%82%D1%8C.md) · [Артикуляция](../05%20%D0%9C%D0%B5%D0%BB%D0%BE%D0%B4%D0%B8%D1%8F%20%D0%B8%20%D1%81%D0%BE%D1%87%D0%B8%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5/%D0%90%D1%80%D1%82%D0%B8%D0%BA%D1%83%D0%BB%D1%8F%D1%86%D0%B8%D1%8F.md).

Отправная цепочка: **сухая запись → монтаж и уровень фраз → Graillon → EQ/компрессия по задаче → de-esser по необходимости → посылы**. Порядок не универсален. Добавляй блок только после объяснения слышимой задачи.

1. Напой мелодию без эффектов и подпиши устойчивые и проходящие ноты по текущим аккордам. Сохрани исходный дубль и его паузы.
2. В Graillon Free согласуй набор разрешённых высот с мелодией. В A minor перед Am может понадобиться G♯ над E7. Если точной маски в режиме нет, сравни хроматический режим или обработай фразы отдельно. Один набор на весь трек не всегда подходит.
3. Сравни мягкую и резкую коррекцию по переходам между нотами. Корректор не исправляет ритм и не придумывает направление фразы.
4. Исследуй pitch и форманты отдельно: октава меняет регистр, формантная окраска меняет характер гласных. Запиши, сохранился ли мелодический контур.
5. EQ используй для слышимой спектральной проблемы, компрессию — для динамики и артикуляции, de-esser — для избыточных свистящих. Проверяй дикцию, окончания и паузы после каждого блока.
6. Delay и реверберацию выбирай по границам фраз; сначала тихие посылы. Для ширины отдельно запиши дабл, а гармонизующий голос сначала сочини по нотам.

**Проверка:** есть сухая версия, по каждому блоку записана цель, главная мелодия читается в миксе и моно. Платные режимы Graillon не являются условием.
