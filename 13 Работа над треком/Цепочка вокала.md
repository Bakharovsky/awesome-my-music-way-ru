# Цепочка вокала

Отправная точка: **сухая запись → монтаж → Graillon → EQ → компрессор → de-esser по необходимости → посылы**. Порядок можно менять по задаче.

1. Запиши понятную мелодию без перегруза входа. Сохрани исходный дубль.
2. Определи тональность и разрешённые ноты. Для заимствованных аккордов настройка может меняться по фразам.
3. В Graillon сравни естественную коррекцию и hard-tune.
4. Отдельно попробуй форманты, сохраняя музыкальную функцию высоты.
5. Только потом добавь реверберацию и delay. Для ширины запиши ещё один настоящий дубль.

Нет обязательного универсального пресета: диапазон, подача и аранжировка важнее копирования чужих чисел.
