# Посылы и шины

Insert обрабатывает сигнал дорожки последовательно. Send отправляет регулируемую долю сигнала на отдельную дорожку возврата. Bus объединяет несколько дорожек для общей обработки.

На общей реверберации установи 100% wet, а её количество меняй посылами. У каждой дорожки остаётся свой сухой звук. На insert обычно нужен dry/wet баланс.

**Попробуй:** направь гитару и вокал в одну реверберацию. Уменьши оба посыла до почти незаметного уровня, затем выключи return и оцени исчезнувшее пространство. Не отправляй return сам в себя.
