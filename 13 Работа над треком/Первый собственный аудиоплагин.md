# Первый собственный аудиоплагин

Это дополнительная ветка после первого законченного трека.

Первый проект — gain: входной буфер умножается на коэффициент, параметр сглаживается, состояние сохраняется. Следующий — фильтр или простой waveshaper. Не начинай с полифонического автотюна.

C++ подходит для исследования существующих кроссплатформенных аудиопроектов. Rust тоже возможен, но перед выбором framework проверь поддерживаемые форматы, сопровождение и лицензии. C# и JS удобны для инструментов вокруг DAW, генерации MIDI и прототипов; поддержка JS в одном хосте не означает загрузку такого эффекта в Waveform.

В аудиопотоке избегай блокировок, файлового ввода-вывода и непредсказуемых выделений памяти. Проверяй тишину, NaN/Inf, разные sample rate и buffer size, смену параметров и восстановление состояния.

**Критерий результата:** Linux VST3 загружается в Waveform, gain не щёлкает при движении ручки, проект после перезапуска сохраняет значение. Упаковка в Nix — отдельный шаг после рабочего прототипа.

Исходники для чтения: [Surge](https://github.com/surge-synthesizer/surge), [BYOD](https://github.com/Chowdhury-DSP/BYOD). Перед заимствованием кода прочитай лицензии.
