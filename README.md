# Музыкальная теория → обработка → хайперпоп

Markdown-база для изучения музыкальной теории через слух, игру, Waveform и собственные композиции. Основной путь — понять ноты, время, гармонию и форму, затем применять плагины под музыкальную задачу.

Открой корень этого репозитория как хранилище Obsidian или читай файлы в любом Markdown-просмотрщике. Сторонние плагины Obsidian не нужны. Все внутренние ссылки — обычные Markdown-ссылки с относительными путями `.md`; сохраняй структуру папок. При переименовании через Obsidian включи автоматическое обновление ссылок.

## Как заниматься

Прочитай понятие → спой или сыграй пример → сформулируй гипотезу → поменяй один параметр → сравни при близкой громкости → сохрани результат в [Журнал занятий](09%20%D0%9C%D0%BE%D0%B8%20%D0%B7%D0%B0%D0%BC%D0%B5%D1%82%D0%BA%D0%B8/%D0%96%D1%83%D1%80%D0%BD%D0%B0%D0%BB%20%D0%B7%D0%B0%D0%BD%D1%8F%D1%82%D0%B8%D0%B9.md). Пиши короткие фрагменты с первых занятий; число прочитанных карточек не заменяет умения объяснить и услышать их действие.

При объединении с личным хранилищем сделай копию и сравни одноимённые файлы. Репозиторий содержит заметки и шаблоны Markdown; аудио, плагины и проекты пользователя в него не включены.
