# README

Готовая Markdown-база для Obsidian: теория музыки, гитара, электронное сочинение и применение в Waveform.

Распакуй архив → открой папку `music-theory-vault` как хранилище Obsidian → открой [[Главная]].

Сторонние плагины не нужны. Связи, свойства, раскрывающиеся ответы и граф поддерживаются самим Obsidian. Конфигурация твоего существующего Obsidian не заменяется.

Начало: [[Как пользоваться базой]] → [[Маршрут обучения]] → [[Практика 01 — Записать рифф]].

Внутренние ссылки используют уникальные имена Markdown-файлов. При переименовании делай это через Obsidian с включённым обновлением ссылок.

## Обновление 28 октября 2026

Открой папку music-theory-vault как хранилище Obsidian и перейди в «Главная» → «Карта — Домашняя студия». Для первого запуска студии: «Стартовый комплект» → «Практика 14 — Проверить студию».

Если объединяешь с уже изменённым хранилищем, сначала сделай копию и сравни одноимённые файлы. Музыкальные плагины устанавливаются отдельно; архив их не содержит.
