## Студия

| Термин | Смысл |
|---|---|
| DI | Сухой сигнал инструмента до виртуального усилителя |
| Buffer | Блок сэмплов обработки |
| Monitoring | Прослушивание входящего сигнала |
| Insert | Последовательная обработка дорожки |
| Send / Return | Посыл и возврат эффекта |
| Bus | Общая шина |
| Wet / Dry | Обработанный / исходный сигнал |
| Sidechain | Управляющий вход обработки |
| Stem | Экспорт отдельной группы или партии; состав оговаривается |
| IR | Импульсный отклик |
| Hard-tune | Нарочито резкая коррекция высоты |
