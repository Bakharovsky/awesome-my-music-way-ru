# Словарь RU-EN

Термины для интерфейса, уроков и поиска. Перевод зависит от контекста.

- **Pitch** — Высота звука. [[Высота звука]]
- **Timbre** — Тембр. [[Тембр]]
- **Semitone / half step** — Полутон. [[Полутон и тон]]
- **Whole tone / whole step** — Тон. [[Полутон и тон]]
- **Sharp / flat / natural** — Диез / бемоль / бекар. [[Диезы и бемоли]]
- **Scale** — Гамма; в контексте также звукоряд лада. [[Гамма и лад]]
- **Key** — Тональность; в другом контексте клавиша. [[Тональность]]
- **Root** — Основной тон аккорда. [[Бас и основной тон]]
- **Tonic** — Тоника. [[Тональность]]
- **Third / fifth** — Терция / квинта. [[Номер и качество интервала]]
- **Triad** — Трезвучие. [[Трезвучие]]
- **Chord progression** — Аккордовая последовательность. [[Аккордовая последовательность]]
- **Voicing** — Расположение голосов аккорда. [[Расположение аккорда]]
- **Inversion** — Обращение. [[Обращение аккорда]]
- **Relative keys** — Параллельные / родственные тональности. [[Родственные мажор и минор]]
- **Parallel keys** — Одноимённые тональности. [[Одноимённые тональности]]
- **Beat** — Доля/пульс; разговорно также бит целиком. [[Ритм и пульс]]
- **Bar / measure** — Такт. [[Размер 4-4]]
- **Time signature** — Музыкальный размер. [[Размер 4-4]]
- **Rest** — Пауза. [[Паузы]]
- **Triplet** — Триоль. [[Триоли]]
- **Velocity** — Параметр силы MIDI-нажатия. [[Velocity]]
- **Quantize** — Квантизировать. [[Квантизация]]
- **Attack / release** — Начальная фаза / затухание после отпускания. [[Огибающая ADSR]]
- **Cutoff** — Характерная частота среза фильтра. [[Фильтр]]
- **Verse / chorus / bridge** — Куплет / припев / бридж. [[Форма песни]]
- **Hook** — Запоминающийся элемент композиции. [[Мотив]]
- **Comping** — Сборка исполнения из выбранных фрагментов дублей. [[Практика 01 — Записать рифф]]
- **Formant** — Форманта. [[Высота и форманты]]
- **Automation** — Автоматизация. [[Автоматизация]]

| Термин | Смысл |
|---|---|
| DI | Сухой сигнал инструмента до виртуального усилителя |
| Buffer | Блок сэмплов обработки |
| Monitoring | Прослушивание входящего сигнала |
| Insert | Последовательная обработка дорожки |
| Send / Return | Посыл и возврат эффекта |
| Bus | Общая шина |
| Wet / Dry | Обработанный / исходный сигнал |
| Sidechain | Управляющий вход обработки |
| Stem | Экспорт отдельной группы или партии; состав оговаривается |
| IR | Импульсный отклик |
| Hard-tune | Нарочито резкая коррекция высоты |
