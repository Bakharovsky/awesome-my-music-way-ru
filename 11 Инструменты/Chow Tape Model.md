# Chow Tape Model

## Для чего

Бесплатная модель магнитной ленты для окраски и движения звука.

## Первое упражнение

Сделай копию гитарного фрагмента и сравни лёгкую обработку с bypass при равной громкости.

## Ограничения

Не обязательный улучшатель каждого канала. Сначала реши, нужен ли конкретному звуку такой характер.

## Установка

Следуй [[Нативные плагины на NixOS]] и [[Сканирование плагинов Waveform]]. Для встроенных инструментов Waveform отдельный установщик не нужен.

[Официальный источник](https://chowdsp.com/products.html). Сведения сверены 28 октября 2026; запуск на твоём компьютере не проверялся.
