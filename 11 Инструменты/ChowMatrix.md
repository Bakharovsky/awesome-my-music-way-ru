# ChowMatrix

## Для чего

Бесплатный творческий delay для сложных повторов и пространственных эффектов.

## Первое упражнение

Начни с одного тихого повтора. Увеличивай feedback постепенно; автоматизируй посыл только на конце фразы.

## Ограничения

Для обычного эха достаточно встроенного delay Waveform. Высокая обратная связь быстро увеличивает уровень.

## Установка

Следуй [[Нативные плагины на NixOS]] и [[Сканирование плагинов Waveform]]. Для встроенных инструментов Waveform отдельный установщик не нужен.

[Официальный источник](https://chowdsp.com/products.html). Сведения сверены 28 октября 2026; запуск на твоём компьютере не проверялся.
