# Micro Drum Sampler

## Для чего

Встроенный инструмент Waveform для набора ударных из отдельных сэмплов.

## Первое упражнение

Назначь kick, snare, closed hat и clap на разные MIDI-ноты. Сделай два такта и измени velocity хэтов.

## Ограничения

Набор одиночных ударов подходит для электроники; реалистичная акустическая установка требует более сложных библиотек.

## Установка

Следуй [[Нативные плагины на NixOS]] и [[Сканирование плагинов Waveform]]. Для встроенных инструментов Waveform отдельный установщик не нужен.

[Официальный источник](https://www.tracktion.com/products/waveform-free-features). Сведения сверены 28 октября 2026; запуск на твоём компьютере не проверялся.
