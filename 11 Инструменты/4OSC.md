# 4OSC

## Для чего

Встроенный синтезатор для первых уроков синтеза без дополнительных установок.

## Первое упражнение

Возьми простой звук, последовательно меняй фильтр, attack и release. Сохрани три варианта.

## Ограничения

Для первого трека достаточно одного синтезатора. Surge XT добавляй по необходимости.

## Установка

Следуй [[Нативные плагины на NixOS]] и [[Сканирование плагинов Waveform]]. Для встроенных инструментов Waveform отдельный установщик не нужен.

[Официальный источник](https://www.tracktion.com/products/waveform-free-features). Сведения сверены 28 октября 2026; запуск на твоём компьютере не проверялся.
