# Guitarix VST

## Для чего

Guitarix.vst — отдельная Linux VST3-обёртка гитарного процессора для работы внутри DAW.

## Первое упражнение

Запиши DI, выбери усилитель и кабинет, сравни чистый и перегруженный варианты на одинаковой громкости.

## Ограничения

Пакет guitarix со standalone или LV2 не обязательно содержит guitarix.vst. Проверяй конкретную сборку. Не добавляй второй кабинет без осознанной причины.

## Установка

Следуй [[Нативные плагины на NixOS]] и [[Сканирование плагинов Waveform]]. Для встроенных инструментов Waveform отдельный установщик не нужен.

[Официальный источник](https://github.com/brummer10/guitarix.vst). Сведения сверены 28 октября 2026; запуск на твоём компьютере не проверялся.
