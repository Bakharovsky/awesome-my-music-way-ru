# Surge XT

## Для чего

Основной бесплатный открытый синтезатор для баса, лидов, пэдов и электронных текстур. Есть нативные Linux-сборки.

## Первое упражнение

На одном пресете напиши бас, затем отдельно изучи фильтр и огибающую. Сохрани свой патч и MIDI.

## Ограничения

Для Waveform выбирай поддерживаемую VST-сборку. Папку пресетов сохраняй вместе с настройками инструмента.

## Установка

Следуй [[Нативные плагины на NixOS]] и [[Сканирование плагинов Waveform]]. Для встроенных инструментов Waveform отдельный установщик не нужен.

[Официальный источник](https://surge-synthesizer.github.io/). Сведения сверены 28 октября 2026; запуск на твоём компьютере не проверялся.
